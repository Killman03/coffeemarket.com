## Что проверено тестами

Независимо вычисленный пример с потерями, комиссиями и налогом; округление;
нулевые продажи; отрицательная прибыль; недостижимая точка безубыточности;
нулевые знаменатели; ограничения чисел/дней/процентов; общая модель сценариев;
схема каталога и происхождение данных; сохранение/восстановление и ошибки
хранилища; мгновенный пересчёт; скрытие результатов при неверном вводе;
смена напитка; фасовка 250 г; валидный и повреждённый импорт файла через File API;
экспорт JSON Blob с проверкой возможности повторного импорта.

## Что проверено браузером

Отображение интерфейса и графика, нулевые продажи, ошибка для 32 рабочих дней,
смена кофейной позиции на 250 г (849 сом → 3396 сом/кг), обозначение отсутствия
товара, сохранение и восстановление после перезагрузки, мобильная компоновка.
Скриншоты сохранены отдельно как пользовательские материалы.

## Ограничения проверки

Драйвер встроенного браузера не вернул событие завершения скачивания JSON
до тайм-аута. Кнопка отработала и показала уведомление; создание корректного
Blob и вызов скачивания отдельно проверены компонентным тестом. Физический
файл в системной папке загрузок этим драйвером не подтверждён.

В сборке Sites есть предупреждения сторонних RSC-плагинов о source map и
неэффективном dynamic import внутренних модулей фреймворка; сборка завершается
успешно. Эти предупреждения не подавлялись. CI-конфигурация добавлена,
но удалённый GitHub Actions в этой сессии не запускался.

Не выполнялись нагрузочные испытания, внешний аудит безопасности и интеграция
с действующим coffeemarket.kg. Docker runtime проверен smoke-запросом;
инфраструктурные настройки реального хостинга остаются этапом переноса.
Автообновления цен нет: это явно помеченный снимок CoffeeMarket MCP.
