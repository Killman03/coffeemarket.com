# Coffee Market — калькулятор и P&L на 3 месяца

Версия 2.2.0. Самостоятельный русскоязычный сайт: рынок и валюта выбираются независимо. Калькулятор бесплатен, без регистрации. Excel дополняет расчёт меню, сценариями и планом/фактом.

Основной репозиторий: [Killman03/coffeemarket.com](https://github.com/Killman03/coffeemarket.com). Правила работы с Git и CI — [docs/REPOSITORY.md](docs/REPOSITORY.md).

## Запуск из чистого Git checkout

Используйте Node.js из `.node-version` и npm. `package-lock.json` хранится в Git; устанавливайте зависимости через `npm ci`.

```sh
npm ci
npm test
npm run typecheck
npm run dev:portable
```

Открыть http://127.0.0.1:3000. Этот режим запускает публичный калькулятор без Sites, базы данных и секретов. Google-style docstrings описывают публичные границы.

## Готовность к переносу

| Возможность                   | Текущее размещение Sites       | Обычный Node.js                                                |
| ----------------------------- | ------------------------------ | -------------------------------------------------------------- |
| Калькулятор и пример Excel    | Работают                       | Работают                                                       |
| Настройки и админка           | D1 и вход через ChatGPT        | Требуются storage/identity адаптеры                            |
| Собственная аналитика         | D1                             | Требуется storage адаптер                                      |
| Персональный Excel в Telegram | Подготовлено, выдача отключена | Нужны адаптеры, серверная конфигурация и подключение менеджера |

Dockerfile собирает Node.js standalone. Он не переносит базу и авторизацию Sites автоматически. План подготовки собственного репозитория и ограничения — [docs/REPOSITORY.md](docs/REPOSITORY.md).

Для полного локального Sites preview: настроить локальную D1 по DEPLOYMENT.md, скопировать `.dev.vars.example` в игнорируемый `.dev.vars` и выполнить `npm run dev`. Без этого preview не предоставляет рабочие данные админки. Node.js standalone не доверяет локальному mock-входу Sites.

## Сборки

- `npm run build` — Sites / Worker.
- `npm run build:portable` и `npm run start:portable` — обычный Node.js / Next.js standalone.
- `npm run build:widget` — независимый ESM-виджет в widget-dist.
- `npm run db:generate` — новые SQL-миграции из схемы Drizzle; ранее применённые миграции не изменять.

## Документация

- docs/REPOSITORY.md — Git, CI, секреты, резервная копия истории и границы переноса.
- ARCHITECTURE.md — слои, контракты, рынки, сценарии и формулы.
- DEPLOYMENT.md — размещение и настройки окружения.
- INTEGRATION.md — встраивание и Django.
- docs/ANALYTICS.md — собственная статистика, приватность, метрики и перенос.
- docs/ADMIN.md — работа с панелью, безопасность и перенос.
- docs/TELEGRAM.md — автоматическая выдача из личного чата менеджера.
- scripts/workbook/README.md — структура Excel, авторинг и воспроизведение проверок.
- VALIDATION.md — выполненные проверки и ограничения.

Выдача персонального Excel остаётся отключённой до настройки бизнес-бота, хранилища, webhook и менеджера. На сайте доступен реальный демонстрационный XLSX; телефоны при отключённой выдаче не собираются. Установка исходников сама по себе не подключает Telegram.

Админка: /admin, вход владельца через ChatGPT. Доступны Telegram, стартовые значения для восьми валют и тексты. Изменения хранятся в БД без повторной публикации. Серверные токены не редактируются и не отображаются в браузере.

Собственная аналитика: /admin/analytics. Сессии, последовательная воронка, источники/кампании, рынок и валюта при входе. Владелец исключён, отказ от статистики доступен посетителю. Django и внешние аналитические сервисы не подключены.
