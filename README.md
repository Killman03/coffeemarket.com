# Coffee Market — калькулятор себестоимости и прибыли

Рабочий прототип для моделирования экономики одного кофейного напитка.
React + TypeScript, React Hook Form, Zod, Decimal.js и Recharts.
Русский интерфейс, KGS, адаптивная компоновка, сохранение и JSON-перенос сценария.
Версия 1.1.0: оформление в стиле coffeemarket.kg, изолированный виджет и отдельная
оболочка предпросмотра. Формулы не менялись.

```sh
npm ci
npm test
npm run typecheck
npm run dev
```

В текущем Sites используется Vinext. Для обычного Node.js-хостинга:

```sh
npm run build:portable
npm run start:portable
```

Каталог: снимок шести публичных кофейных позиций, полученный через CoffeeMarket
MCP 09.11.2026. Цены и остатки не обновляются автоматически. Рецепты, молоко,
упаковка, цена продажи и расходы — редактируемые демонстрационные значения.
Потенциальная прибыль включает только указанные пользователем расходы.

Формулы находятся исключительно в src/domain. В проекте нет Python, манипуляций
sys.path/PYTHONPATH, токенов MCP или подключения браузера к приватному CRM.
