# Coffee Market — калькулятор и P&L на 3 месяца

Версия 2.2.0. Самостоятельный русскоязычный сайт: рынок и валюта выбираются независимо. Калькулятор бесплатен, без регистрации. Excel дополняет расчёт меню, сценариями и планом/фактом.

Основной репозиторий: [Killman03/coffeemarket.com](https://github.com/Killman03/coffeemarket.com). Правила работы с Git и CI — [docs/REPOSITORY.md](docs/REPOSITORY.md).

## Запуск из чистого Git checkout

Используйте Node.js из `.node-version` и npm. `package-lock.json` хранится в Git; устанавливайте зависимости через `npm ci`.

```sh
npm ci
npm test
npm run typecheck
npm run dev:portable
```

Открыть http://127.0.0.1:3000. Этот режим запускает публичный калькулятор без Sites, базы данных и секретов. Google-style docstrings описывают публичные границы.

## Готовность к переносу

| Возможность                | Sites                          | Node.js                                                 |
| -------------------------- | ------------------------------ | ------------------------------------------------------- |
| Калькулятор и пример Excel | Работают                       | Работают                                                |
| Хранение настроек          | D1                             | PostgreSQL / Drizzle                                    |
| Админка                    | Вход через ChatGPT             | Better Auth / PostgreSQL; владелец создаётся оператором |
| Собственная аналитика      | D1                             | PostgreSQL; отчёты доступны вошедшему владельцу         |
| Telegram P&L               | Подготовлено, выдача выключена | PostgreSQL-адаптер готов; нужны бот и менеджер          |

Node.js подключает адаптеры штатным Next.js startup hook. Dockerfile содержит runner и migrator. Конфигурация, миграции, права, readiness и интеграционные тесты — [docs/POSTGRESQL.md](docs/POSTGRESQL.md). Данные и авторизация Sites не переносятся автоматически.

Для полного локального Sites preview настроить локальную D1 по DEPLOYMENT.md, скопировать .dev.vars.example в игнорируемый .dev.vars и выполнить npm run dev. Node.js не доверяет локальному mock-входу Sites.

## Сборки

- `npm run build` — Sites / Worker.
- `npm run build:portable` и `npm run start:portable` — обычный Node.js / Next.js standalone.
- `npm run build:widget` — независимый ESM-виджет в widget-dist.
- `npm run db:generate` — новые SQL-миграции из схемы Drizzle; ранее применённые миграции не изменять.

Выдача персонального Excel остаётся отключённой до настройки бизнес-бота, хранилища, webhook и менеджера. На сайте доступен реальный демонстрационный XLSX; телефоны при отключённой выдаче не собираются. Установка исходников сама по себе не подключает Telegram.

Админка: /admin, на Sites вход через ChatGPT; на Node.js — email/пароль владельца через Better Auth. Для Node задайте BETTER_AUTH_SECRET и выполните npm run admin:create с отдельным ADMIN_DATABASE_URL; полный порядок — docs/NODE_AUTH.md. Доступны Telegram, стартовые значения для восьми валют и тексты. Изменения хранятся в БД без повторной публикации. Серверные токены не редактируются и не отображаются в браузере.

Собственная аналитика: /admin/analytics. Сессии, последовательная воронка, источники/кампании, рынок и валюта при входе. Владелец исключён, отказ от статистики доступен посетителю. Django и внешние аналитические сервисы не подключены.
